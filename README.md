AKVA+ is a full-stack e-commerce web application for a plumbing products store.

The project includes a modern React frontend, a Node.js/Express backend, and a MongoDB database.  
It implements the key functionality of an online store: product catalog, search and filtering, product details page, shopping cart, favorites, user authentication, checkout, user profile, order history, and admin product management.

---

## Features

- Modern landing page
- Product catalog
- Product search
- Filtering by category, country, and price
- Product details page
- Shopping cart
- Cart quantity management
- Favorites list
- User registration and login
- JWT authentication
- User profile
- Order history
- Mock checkout flow
- Admin panel
- Product creation and deletion
- MongoDB data storage
- Responsive user interface
